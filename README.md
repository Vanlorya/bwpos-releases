# BWPos — bản phát hành

Kho này chỉ chứa **bộ cài BWPos cho Windows** và file mô tả phiên bản (`latest.yml`) để phần mềm đã cài **tự cập nhật**. Không có mã nguồn.

- Tải bộ cài: mục **Releases** bên phải.
- Phần mềm dùng thử 7 ngày; sau đó cần License Key. Liên hệ Zalo **033.5258.322**, gửi kèm *ID Máy* (xem trong phần mềm).
- Máy đang chạy BWPos 1.7.4 trở lên tự tải bản mới và cài khi tắt phần mềm cuối ngày; dữ liệu được sao lưu trước khi nâng cấp.
